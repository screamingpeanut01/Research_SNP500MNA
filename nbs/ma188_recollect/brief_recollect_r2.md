### 2-2. 결과 분류

## 3. 출력

```json
{
  "deal_id": "K012",
  "ciq_id": "IQTR...",
  "checks": [
    {"field": "target_op_pre", "class": "미완", "retry": "채움",
     "reason": "이번에 연 출처를 모두, 결과와 함께", "after": "재수집 뒤의 전체 값"}
  ],
  "corrections": {"target_op_pre": "값이 바뀐 칸만"},
  "impairment_class_after": null,
  "evidence_add": [ {"field": "...", "phase": "...", "event_date": "...", "event_type": "...", "content": "...",
                     "url": "...", "doc_type": "...", "doc_date": "...", "doc_id": "..."} ],
  "other_issues": "",
  "summary": "한두 문장"
}
```

- `checks`에는 `targets`의 칸을 모두, 빠짐없이 넣는다.
- `class`는 `공개 자료 없음` 또는 `미완`, `retry`는 `채움`, `일부 채움`, `못 찾음` 가운데 하나만 쓴다. 설명은 `reason`에 쓴다.
- `corrections`의 키는 `targets`에 있는 열 이름이어야 한다(`impairment_class` 제외).
- 근거 행의 키는 위의 아홉 개 그대로다.
- JSON이 파싱되는지 `python -X utf8 -c "import json;json.load(open(r'<경로>',encoding='utf-8'))"`로 확인한다.
